# MVP Scope

The first Aursuq release proves one end-to-end business cycle:

1. User account and authentication
2. Seller application and verification state
3. Seller store and basic storefront customization
4. Independent seller product listings and variants
5. Inbound warehouse shipment creation
6. Carton barcode generation and receiving
7. Discrepancy recording with photos
8. Warehouse location assignment and inventory movements
9. Customer browse/search/cart
10. Checkout with test payment integration first
11. Inventory reservation after payment success
12. One customer order with internal seller shares
13. Warehouse pick and pack
14. Shipping/tracking integration
15. Frozen seller proceeds
16. Release to available wallet after delivery
17. Seller sales ledger and payout request

Deferred: advanced returns, advanced analytics, full mobile apps, advanced ads, sophisticated Store Builder, and complete dispute automation.
